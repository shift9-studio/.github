# Social logo sources

These locally served marks are used only as links to Shift-9 Studios profiles.
Their shapes and brand colors follow each platform's official asset guidance.

- Instagram: https://about.meta.com/brand/resources/instagram/instagram-brand/
- Facebook: https://about.meta.com/brand/resources/facebookapp/logo/
- LinkedIn `[in]`: https://brand.linkedin.com/in-logo
- TikTok: https://developers.tiktok.com/doc/getting-started-design-guidelines
- GitHub Invertocat: https://brand.github.com/foundations/logo

Do not recolor, distort, add effects to, or combine these marks with the Shift-9 mark.
