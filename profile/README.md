## Studio systems

- **Automation Systems**: the local production control plane for specialist routing, decision gates, searchable project memory, and code and visual proof.
- **Bring Up Desk**: a human-gated production system for researched hardware and AI explainers, from primary sources through private-draft upload.
- **Titanium Forge Pro**: a portable React component workbench with live demos and copyable production snippets.
- **Game Design Forge**: Unreal Engine R&D for assembling game systems through matched, reusable parts.

## Work with Shift-9

We design and build product websites, production apps, automation systems, and interactive 3D experiences. One studio carries the work from product direction and interface design through engineering and release.
